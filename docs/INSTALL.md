# Install Right Shape

Bring one AI job, an existing capability or a repository portfolio. You get a placement card or an audit with source routes, limits and the next test.

## From the public source

Use Git and Python 3.11 or later. These commands install the complete method into a skills-parent directory:

```sh
git clone https://github.com/michaeljabbour/amplifier-skill-right-shape.git
cd amplifier-skill-right-shape
python3 scripts/capability.py install --dest ~/.agents/skills
```

Choose the discovery directory supported by your agent. `~/.agents/skills` is an example. Start a new session if your host only discovers skills at startup, then ask for Right Shape by name with one task. Read the returned result and its sources before acting on it.

The installer refuses conflicting files. Keep your changes before deliberately replacing a copy. It does not register a host, start a service or prove model behavior.

## Without a checkout

Download the complete ZIP from [the public site](https://michaeljabbour.github.io/amplifier-skill-right-shape/#use-skill), extract it and place the whole skill folder in your host’s skills directory. Keep all references, helpers and license files together. The single SKILL.md download is for reading; use the whole folder to install.
